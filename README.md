# EkqiModYT

Набор патчей ReVanced для YouTube с защитой OLED-экрана от выгорания в Shorts.

## Защита от выгорания

Патч **OLED burn-in protection**:

- добавляет кнопку-щит в левый верхний угол Shorts;
- по нажатию быстро включает и выключает защиту;
- периодически сдвигает статичные элементы интерфейса Shorts на несколько пикселей;
- не сдвигает `SurfaceView`/`TextureView`, в которых отрисовывается само видео;
- возвращает элементы в исходное положение при выходе из Shorts или отключении функции.

Настройки находятся внутри YouTube:

`Настройки → ReVanced → Shorts → Защита OLED от выгорания`

Доступны включение защиты, показ кнопки, интервал и величина сдвига.

> Функция снижает риск неравномерного износа OLED-пикселей, но не может гарантировать полную защиту экрана.

## Поддерживаемые версии YouTube

- 20.14.43
- 20.21.37
- 20.26.46
- 20.31.42
- 20.37.48
- 20.40.45

Рекомендуется использовать последнюю версию из списка.

## Сборка

Требуется JDK 17 и доступ к интернету. Авторизация в GitHub Packages не нужна: совместимый ReVanced CLI 6.0.0 загружается из публичного GitHub Release, а его SHA-256 проверяется перед сборкой.

```powershell
.\gradlew.bat :patches:buildAndroid --no-daemon
```

Готовый файл `.rvp` появится в `patches/build/libs`. Его можно импортировать в ReVanced Manager или передать ReVanced CLI как дополнительный набор патчей. APK YouTube в репозитории не хранится и не распространяется.

GitHub Actions также прикладывает собранный `.rvp` к каждому запуску workflow **Build patches**.
